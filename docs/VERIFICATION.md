## 本次修复的实测问题

- Windows 的 `floating` 层级可能在“排到任务栏后方”时丢失原生 topmost，改为显式 `pop-up-menu` 层级，置顶开关与重启检查均通过。
- 隐藏 GUI 进程启动会影响首次显示窗口，启动器改为正常 GUI 启动；清除宿主的 `ELECTRON_RUN_AS_NODE`，保留正式 Electron 沙箱设置。
- 辅助面板在页面加载完成后显示，保留明确的原生窗口标题。
- 快速拖动首段可能发生在 IPC 抵达前，改为校验窗口内抓取点，并在结束时补采样；实际快速拖动复测通过。
- Windows 分数 DPI 下窗口大小存在最多 1 DIP 原生舍入，自动测试按此容差检查。
