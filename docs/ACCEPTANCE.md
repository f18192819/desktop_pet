# 人工验收

在 Windows 10/11 运行 `npm start` 或便携目录中的 `Emma.exe`。

| 检查 | 操作 | 预期 |
|---|---|---|
| 启动 | 启动程序并查看其他普通窗口上方 | 艾玛显示，背景透明，无边框、菜单栏、任务栏项 |
| 素材播放 | 右键 → 工作面板，逐一预览八个动作 | 顺序推进、无白底/拉伸/缺帧闪烁；happy/angry 一轮后 idle |
| 单击 | 单击艾玛，等待约 450ms | happy 一轮后 idle |
| 双击 | 双击艾玛 | 聊天打开，配置服务并创建会话后可以发送 |
| 拖动 | 左键按住角色拖动，再松开 | 移动时 dragged，松开 idle；不误开聊天/触发 happy |
| 取消拖动 | 拖动时 Alt+Tab 或切换到其他窗口 | 结束拖动，不继续跟随鼠标 |
| 右键 | 在角色上右键 | 聊天、工作、暂停/恢复、设置、隐藏、退出均可用 |
| 暂停 | 右键暂停，等待，再恢复 | 画面冻结；恢复后继续播放 |
| 大小 | 设置为 120、320、600，并保存 | 窗口和角色等比例缩放，仍可拖动/右键 |
| 置顶 | 设置中关闭/打开置顶 | 普通窗口覆盖行为随设置切换 |
| 睡眠 | 设置睡眠为 5 秒，结束预览后不操作 | 5 秒后 sleeping；点击/拖动立即唤醒；再将设置恢复 300 秒 |
| 托盘 | 隐藏桌宠，再从托盘显示 | 隐藏后进程继续，托盘可恢复；聊天/设置能打开 |
| 保存 | 移动桌宠并修改设置，从托盘退出再启动 | 位置、大小、置顶、动画开关、睡眠时间、皮肤恢复 |
| 多显示器 | 拖到副屏（含主屏左侧）并重启 | 在副屏恢复，负坐标正确 |
| 断开屏幕 | 位于副屏时断开副屏 | 桌宠回到有效屏幕的工作区内 |
| 显示缩放 | 切换 Windows 缩放/分辨率 | 角色比例保持、窗口修正到工作区 |
| 单实例 | 重复启动同一应用 | 不出现多个桌宠，已有桌宠显示 |
| 退出 | 右键或托盘退出 | 所有面板和托盘消失，进程结束 |

多屏硬件、不同 DPI、Windows 合成器的实际外观仍应在目标用户设备上复核。自动化几何测试不能代替多显示器实机验证。

自动检查：`npm run typecheck`、`npm run build`、`npm test`、`npm run test:electron`。Electron 冒烟测试使用独立 profile，并真实启动两次验证恢复；不修改实际用户配置。

第二阶段的服务配置、加密凭据、流式聊天、多会话、异常/取消和用量验收见 [STAGE2.md](STAGE2.md)。真实连接测试可能计费，核心自动测试使用模拟网络。


## 第三阶段

参考 [STAGE3](STAGE3.md) 的逐项验收与限制。新增文件 Agent、一次性审批、任务持久化和手动继续，保留普通聊天与动画验收。Shell 原生安全探测失败（外部删除、loopback），界面必须显示禁用。3.1 的文件代理回归覆盖并发链接替换、提交前故障注入及目录回滚，实测范围见 [原生文件代理](STAGE3.md#31-原生文件代理2026-11-20)。

## 3.3 Windows 命令安全

1. 运行 `npm ci`、`npm start`。在设置选择专用测试工作区，把「创建或修改文件」设为「每次询问」。
2. 在工作面板请求创建一个测试文件。审批出现后在设置将该工具设为「禁止」。卡片应立即显示「已撤销」，批准和拒绝按钮消失，测试文件保持不存在。
3. 核对 Shell 默认显示「每次询问」。改为「始终允许」后，工作面板仍应显示 Shell 已禁用。若已配置模型并由模型发出有效的 Shell 调用，记录应显示失败及原因，不出现退出码和输出。
4. 运行 `npm test`。原生 Job Object 夹具只启动固定测试程序，验证进程树控制。Windows 11 家庭版未运行完整隔离沙箱。26 项安全验收逐项状态见 [3.3 交付记录](STAGE3.md#33-windows-命令安全)。

## 3.3.1 Shell 审批和虚拟化验收

1. 通过 `npm test` 验证 Shell 或工作区外读取设为「每次询问」时出现审批记录。将其中一项设为「禁止」，或停止当前任务，旧审批 ID 应立即失效。
2. 若使用已配置模型手动验证，让模型生成一条结构化 Shell 请求。卡片应显示命令、参数、工作目录、只读路径和超时时间。点击「仅批准本次请求」后，工具记录应显示「Shell 已禁用」，没有退出码、终端输出或文件变更。
3. 原生 Job 夹具另外验证固定进程树超时退出。完整的命令沙箱仍需独立 Windows 来宾、可信运行时和文件交换后端。带真实命令和宿主 sentinel 的 15 项结果见 [3.3.1 安全验收](STAGE3.md#331-shell-审批和虚拟化验收)。
